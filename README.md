# QuickFill

A simple Chrome extension that keeps your most-used application details in one place, so you can copy them in one click while filling out job, internship, or scholarship forms.

**Store once. Copy quickly. Continue your application.**

## Why QuickFill?

Online applications ask for the same details again and again:

- Name
- Email address
- Phone number
- LinkedIn profile
- GitHub profile
- Portfolio website
- Other links or short text

Instead of switching tabs or searching through notes, keep everything in the extension and copy what you need.

## Features

- Store your frequently used details in one place
- Copy any saved item with one click
- Works from the Chrome toolbar
- Data stays in your browser's extension storage

## Installation

You do not need the Chrome Web Store. Run it from source using Developer Mode.

1. Clone the repository:

   ```bash
   git clone https://github.com/Abhishek-Kadavergu/chrome-extension.git
   cd chrome-extension
   ```

2. Open Chrome and go to `chrome://extensions/`.
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked**.
5. Select the `chrome-extension` folder.

QuickFill will now appear in your extensions list. Click the puzzle icon in the toolbar and pin it for easy access.

## How to Use

1. Click the QuickFill icon in the Chrome toolbar.
2. Add your details, for example:

   | Field     | Example                            |
   |-----------|------------------------------------|
   | Name      | Your Name                          |
   | Email     | your-email@example.com             |
   | LinkedIn  | https://linkedin.com/in/your-profile |
   | GitHub    | https://github.com/your-profile    |
   | Portfolio | https://your-portfolio.com         |

3. When an application asks for your LinkedIn profile, open QuickFill, click the LinkedIn entry to copy it, and paste it into the form.

That is it.
